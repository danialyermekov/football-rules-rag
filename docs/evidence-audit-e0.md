# Проверка evidence перед E0 / протокол v2

Дата: 23 октября 2026. Проверку выполнил тот же AI coding assistant, который создавал датасет; независимым экспертным ревью она не является.

## Объём и способ проверки

Список выбран до нового retrieval-run: FR001, FR002, FR004, FR006, FR010, FR017, FR028, FR065, FR066, FR090, FR091, FR093. Это 12 dev-ситуаций / 24 вопроса RU/EN. Выбор целевой: есть простой успешный пример, ошибки порядка/поиска, составные основания, multi-page evidence и случаи без gold-чанков по v1. Это не случайная оценка качества всего датасета.

Для каждой ситуации прочитаны вопросы и эталонные ответы RU/EN и точные EN/RU-фрагменты всех `required_evidence` из неизменного исходного `text`. Проверки координат и хешей выполняются валидатором датасета. Визуальная проверка всех PDF-страниц не проводилась; изменения правил по памяти не подставлялись вместо редакции 2026/27.

|---|---|---|
| FR001 | `ball_out`: полное пересечение линии | Прямое соответствие вопросу и ответу на обоих языках |

## Решение для E0

- `scenarios.jsonl`, `evidence.jsonl` и их версии/хеши не меняются. Явных противоречий ответов прочитанным основаниям в этой выборке не обнаружено; это не доказательство отсутствия ошибок в остальных данных.
- Не сокращаем evidence после просмотра результатов, чтобы искусственно повысить метрики. Для минимальных смысловых оснований потребуется отдельная версия разметки и переоценка всех конфигураций.
- В v2 `complete_evidence` означает полноту **размеченных фрагментов**, а не независимую гарантию минимально достаточного юридического обоснования ответа.
- Возможные альтернативные источники не добавлены как новые AND-основания. OR-группы пока не размечены и evaluator их не реализует; результаты интерпретируются относительно текущего gold.
- Широкие shared evidence и неполнота альтернатив остаются существенным ограничением E0. Показатели дополняются непрерывным coverage, строгим покрытием и просмотром отдельных вопросов.

Для воспроизводимости full run сохраняет хеши source manifest, датасета и очищенных страниц, а также этот отчёт и используемый код.

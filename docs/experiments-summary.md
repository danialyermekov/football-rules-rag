# Сводка экспериментов (E0–E25, G0–G13, Q1–Q4)

Все исследовательские циклы проводились на dev-части синтетического датасета (**75 dev / 25 test ситуаций**; для retrieval использовались **71 dev-ситуация = 142 вопроса RU/EN** с обязательным evidence). Тестовый сплит (`25` ситуаций) сохранён нетронутым для финальной проверки.

Полные сырые журналы, протоколы и промежуточные скрипты сохранены в git-теге `archive/research-experiments` и тематических ветках `experiment/*`.

---

## 1. Retrieval (`E0`–`E25`)

Основная метрика — **Complete Evidence Rate (CER)** при глубине пула `50` кандидатов и бюджете контекста `2048` токенов.

| Опыт | Конфигурация | CER RU / EN | Evidence Recall RU / EN | Решение |
|---|---|---:|---:|---|
| **E0** | `BAAI/bge-m3` Dense, чанки 1000/150 | 56.34% / 69.01% | 57.51% / 73.24% | Базовая точка v2 |
| **E1** | BM25 Okapi (`k1=1.2`, `b=0.75`) | 59.15% / 70.42% | 62.68% / 75.59% | Сильный lexical baseline |
| **E2** | Hybrid: BGE Dense + BM25 → RRF60 | 63.38% / 69.01% | 66.43% / 74.18% | Подтвердил пользу hybrid на RU |
| **E3–E4b** | BGE cross-encoder поверх Dense20 / RRF20 / RRF50 | до 67.61% / 76.06% | до 72.77% / 80.05% | Полезно, но заметная задержка |
| **E5–E7** | Чанки `600/150`, `1600/150`, `1000/0` (Dense) | 54.93–63.38% / 66.20–69.01% | — | Универсального плюса нет; оставили `1000/150` |
| **E9** | `Qwen3-Embedding-0.6B` Dense | 56.34% / 71.83% | 60.80% / 77.00% | Быстрее и точнее на EN |
| **E10** | **Qwen3 Dense50 + BM2550 → RRF60** | **66.20% / 76.06%** | **69.72% / 80.52%** | **Принят как быстрый рабочий default** |
| **E12** | `multilingual-e5-large` Dense | 56.34% / 63.38% | 58.69% / 66.20% | Отклонён (хуже контроля) |
| **E13–E14** | Приоритет соседних чанков / продолжений списка | 64.79–70.42% / 74.65–80.28% | — | Смешанный эффект по языкам; отклонён |
| **E15** | **E10 + `Qwen3-Reranker-0.6B`** | **70.42% / 77.46%** | **73.00% / 82.86%** | **Кандидат качества** (`--rerank` в CLI, p50 +3.7–5.1 с) |
| **E16** | Qwen Dense + BGE-M3 learned sparse → RRF60 | 60.56% / 70.42% | 64.55% / 75.59% | Отклонён (хуже BM25) |
| **E17** | Qwen Dense + BM25 со Snowball stemming | 60.56% / 77.46% | 64.32% / 81.92% | Отклонён (просадка на RU) |
| **E18** | Rank fusion E10 + Qwen reranker | 69.01% / 76.06% | 73.47% / 81.92% | Отклонён (ниже E15) |
| **E19–E20** | Query rewriting / extractive phrases (Gemini) | 66.20–67.61% / 74.65–80.28% | — | Отклонены (смысловой drift в E19) |
| **E21–E25** | Локальный контекст-пакинг (predecessor/anchor/successor, compaction, full-union rerank) | до 77.46% / 85.92% | до 81.46% / 88.50% | Исследовательские оффлайн-опыты; не меняли CLI default |

## 2. Generation и качество оценки (`G0`–`G13`, `Q1`–`Q4`)

| Цикл | Что проверяли | Ключевой вывод |
|---|---|---|
| **G0–G2** | Базовый `SYSTEM_PROMPT`, пустой/нерелевантный контекст, строгий промпт | Выявлен риск ответов «из памяти» при пустом контексте; добавлен локальный `guard_empty_context`. Более строгий промпт дал регрессии и не принят. |
| **G3–G4** | Четыре метрики Ragas; ограниченный выбор ссылок (`S1`, `S2`) | Ограниченный формат ID улучшил синтаксис ссылок, но вызвал регрессию смысла на части кейсов; сохранён исходный формат `document_id:pdf_page`. |
| **G5–G8** | E10 против E15; focused prompt; sufficient contexts; evidence-check schema | Более полный контекст (E15 / sufficient) поднимает Factual Correctness (напр. `0.6800 → 0.7475` RU), но не устраняет ошибки применения правил к фактам. Focused и Evidence-check схемы отклонены. |
| **G9–G13** | Сравнение `gemini-2.5-flash-lite`, `gemini-3.8-flash` и `gemini-4-argon` | `gemini-3.8-flash` лучше держит границы источников на контрольных случаях; `gemini-4-argon` в ~3.1 раза дороже без устойчивого преимущества. Default оставлен на `gemini-2.5-flash-lite`. |
| **Q1–Q4** | Ручной аудит 48 ответов, альтернативные evidence, проверка целостности ответа | Показаны ограничения автоматического LLM-judge (разбиение условий в Ragas Faithfulness и краткость эталонов в Factual Correctness). Нужна независимая экспертная калибровка перед финальным test-прогоном. |

## Итоговый рабочий стек в `main`

- **Chunking:** `1000` символов, overlap `150`, без перехода между страницами.
- **Retrieval (default):** Hybrid `Qwen3-Embedding-0.6B` + `BM25` → `RRF60` (`k=50` на ветвь) → `pack_context` (`2048` токенов).
- **Reranking (опционально `--rerank`):** `Qwen3-Reranker-0.6B` поверх кандидатов Hybrid.
- **Generation:** `gemini-2.5-flash-lite` (доступны также `gemini-3.8-flash` и `gemini-4-argon`), structured JSON output, локальный отказ при пустом контексте и пост-проверка `valid_citations`.

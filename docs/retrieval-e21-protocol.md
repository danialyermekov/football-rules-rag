# E21: соседние части правила после Qwen reranker

Протокол зафиксирован до расчёта результатов, 28.10.2026.

Гипотеза: реранкер E15 поднимает подходящий пункт, но отдельные условия и
последствия лежат в соседнем фрагменте. Один предшественник и одно продолжение
могут сохранить связность текста при прежнем бюджете.

Использовать FINISHED E15 b8b229800f4246d090eea03a4d5c9900 и его142 dev-вопроса
(71 на язык). Прежние773 chunks1000/150, Qwen embeddings, Hybrid dense50/BM2550
RRF60 и Qwen reranker. Новых embedding/search/reranker/API запросов нет.
Проверить hashes корпуса, разметки и точное совпадение всех кандидатов.

Единственное изменение: обходить сохранённый reranked top50. Для каждого ещё
не посещённого anchor вывести найденного предшественника, anchor, найденного
successor, по одному, без рекурсивного расширения и без добавления новых chunks.
Связи — существующий chunk_successors: соседство внутри страницы, а переход
на следующую страницу только если она начинается с bullet. Документ/язык/редакция
должны совпадать. Затем прежний pack_context целых chunks с BGE budget2048.
Это эвристика физической близости, не semantic parser Law/section. Связность
не гарантирована, если часть группы не помещается в бюджет; новых правил
упаковки и gold-aware выбора нет. E13/E14 меняли только successor на E10,
здесь двустороннее соседство применяется после E15. Вклад этих отличий отдельно
не изолируется: сравнивается один заранее заданный рецепт.

Smoke3 вопроса, native MLflow dataset/scorers/evaluate и trace readback, затем
полный142. CER, Strict CER, evidence recall/coverage и redundancy, отдельно RU/EN.
Сравнить с E10 и E15, парные исправления/регрессии, bootstrap2000 seed42 по71
scenario с общими resamples RU/EN. Исторический dev многократно использован;
интервалы не подтверждают независимую generalization. Время — только replay
ordering/packing, не ускорение полного RAG. Test не использовать.

До генерации: нужен рост среднего CER относительно E15 без снижения одного
языка более чем на одну ситуацию (1/71) и ручная проверка изменённых источников.
При провале остановить платную часть; результат всё равно записать. При успехе
зафиксировать отдельный generation protocol с тем же Gemini/prompt и пятью
метриками, не менять одновременно промпт и retrieval. Default во время опыта
сохранён. Расходы retrieval0USD, embedding caches и индекс не меняются.
